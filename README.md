# Blender Add-ons by bussiartifex

A collection of free, open-source add-ons for Blender, released under the GPL-3.0-or-later license.

| Add-on | What it does | Blender |
|---|---|---|
| [Vertical Timeline](vertical_timeline) | A vertical scrubbing timeline, as a viewport overlay or in its own area | 4.2+ |
| [Node Dock](node_dock) | A dock in the Geometry Node Editor to store nodes and reuse them in any file | 4.2+ |
| [Physically Based](physically_based) | Real-world materials, lights and cameras from [physicallybased.info](https://physicallybased.info) | 4.2+ |
| [Phone Gyro](phone_gyro) | Rotate the camera, objects, bones or the viewport with an Android phone | 4.2+ |
| [DualSense Controller](dualsense_controller) | Fly the camera and viewport and move objects with a PS5 controller | 4.3+ |

## Installation

The easiest way is from inside Blender: **Edit > Preferences > Get Extensions**, search for the add-on and click **Install**.

To install by hand, download the add-on's `.zip` and drag it into Blender, or use **Edit > Preferences > Get Extensions > ⌄ > Install from Disk**.

## Reporting bugs and asking for help

Open an [issue](https://github.com/bussiartifex/Blender_Addons/issues/new/choose) and choose **Bug report** or **Feature request**.

To get a fix faster, include:

- the add-on name and version (shown in **Preferences > Add-ons**)
- your Blender version and operating system
- what you did, what you expected and what happened instead
- any error text from **Window > Toggle System Console** (Windows) or the terminal you started Blender from
