# Vertical Timeline

A vertical timeline for scrubbing animation, placed at the side of your workspace. The first frame is at the bottom and the last frame at the top. It always shows the full frame range (or the preview range), with no zoom.

## How to use

- **Overlay:** click the clock button in the 3D Viewport header to show the timeline on top of that viewport. Each viewport has its own toggle.
- **Dedicated area:** use **View > Vertical Timeline Area** to open the timeline in its own area on the left. Use it again to close it.

### Controls

| Action | Result |
|---|---|
| Click or drag | Scrub to a frame |
| Mouse wheel or two-finger trackpad scroll | Step frame by frame |
| Space | Play / pause |
| Left / Right arrow (in the area) | Previous / next frame |
| Up / Down arrow (in the area) | Jump to the next / previous keyframe |
| Shift + Left / Right arrow (in the area) | Jump to the start / end |

The settings for appearance and trackpad scrolling are in **Preferences > Add-ons > Vertical Timeline**.

## Requirements

Blender 4.2 or newer.
