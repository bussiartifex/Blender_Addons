# Node Dock

A dock at the top or bottom of the Geometry Node Editor where you can drag nodes and node groups to store them, then drag them back out in any file, in any session.

## How to use

1. Click the bookmark button in the Geometry Node Editor header to show the dock.
2. Select nodes and drag them onto the dock (or use **Node > Add Selected to Node Dock**) to store them.
3. Drag a tile out of the dock to place a copy of the stored nodes.
4. Double-click a tile to rename it, or right-click it for more options (rename, delete).

Stored items are saved as small `.blend` files in a library folder, so they survive restarts. **Preferences > Add-ons > Node Dock** shows the folder, the dock position and the **Reuse Existing Data** option, which reuses node groups and materials already in the file instead of making duplicates.

## Requirements

Blender 4.2 or newer.
